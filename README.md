# One Word for Your Wi-Fi

Entry for make.fun's "One Word for Your Wi-Fi" bounty ($2).

## The word

**Ghosting** — home Wi-Fi vanishes mid-call, mid-game, mid-download, with no
warning and no goodbye. Exactly like being ghosted. It is funny at once,
true to how home Wi-Fi actually behaves, a fresh angle (Wi-Fi as a bad date)
instead of the usual "slow" / "laggy" / "flaky", and instantly understood
with no context. It would also make a perfect network name.

## Run it

```sh
python3 main.py
```

Writes the single word to `/output/entry.txt` (8 characters, deterministic —
the same word on every run).
